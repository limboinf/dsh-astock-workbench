# 决策记录（ADR 简化归档）

> 原两份 ADR（0001、0002，2026-09-06 grilling 产品审判定案）简化合并于此。

## 0001 产品使命定位：AI 投研助理 > 复盘引擎

- 第一使命 **AI 投研助理**：基于用户真实持仓、现金与画像，给出同花顺给不了的直接投资建议。
- 第二使命 **复盘引擎**：决策日志 + 每周深度复盘，帮用户形成自己的投资纪律与理念。
- 功能去留唯一尺子是「场景价值」：是否支撑同花顺给不了的 AI 分析场景。
- 原 MVP「盯盘」定位作废；面板重定位为**宏观驾驶舱**（组合宏观感 + AI 决策参考载体，
  个股明细看同花顺）。5s 轮询经用户拍板保留（2026-09-06）。
- 每日简报双轨：盘后 cron 简报（自动落 briefings/）+ 每周深度复盘（AI 起草、
  用户确认后才落 reviews/，AI 不自动落库）。
- profile.json 画像维持轻量现状，结构化纪律红线方案被否决。

## 0002 投资建议契约：直接建议 + 免责声明 + 用户自担

- 原 astock-briefing 技能「不给投资建议」条款与第一使命冲突，2026-09-06 废除。
- 新契约：**AI 直接给出买卖操作参考；必须引用工具返回的真实数字；必须附免责声明；
  最终决策与后果由用户自行承担。**
- 被否方案：条件-动作契约（不给裸指令）、分渠道（交互式给/简报不给）。
- 保留「数字必须引用工具返回」条款——它管事实准确性，与建议解禁不冲突。
- 配套「建议记分卡」2026-09-07 经用户拍板**取消**（依赖人工确认补录，维护成本
  超出个人使用预算）；代价是 AI 建议质量没有系统化对账回路。
